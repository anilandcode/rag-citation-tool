Questions before you click demo.

Straight answers. No roadmap cosplay.

Is the demo using my documents?

No. It runs on a fixed public sample corpus so anyone can try the path. An audit uses your docs under a scoped agreement.

What if the API host is offline?

The demo UI can fall back to offline sample answers so the product story still reads. Production work is separate.

Do you sell seats like a SaaS?

Not as a multi-tenant product today. You get a live demo, an accuracy audit, or a custom pipeline left in your environment.

Who owns the code after a build?

You do, unless we agree otherwise in writing. The point of Leave is handoff.
